# Hotwords para sherpa-onnx (modified_beam_search + bpe.vocab sintético). Una por línea.
# Solo términos críticos, bancos y apps: la jerga queda afuera a propósito (jerga.txt), porque
# subirle el puntaje a palabras comunes aumenta las inserciones (PLAN-VOZ-REAL.md §5).
# Las mayúsculas son las que produce el modelo Kroko (pone mayúscula a nombres propios y al
# empezar la frase). Tiene mayúsculas solo en las palabras que suelen abrir una frase: el resto
# va en minúscula. Para ver cómo se parte cada una: python hotwords.py
# Las secciones («# [nombre]») sirven a medir_voz_real.py para el recall por grupo.
# «número(s)» queda afuera aunque esté en PATRONES: es demasiado común y su boost metería inserciones.
