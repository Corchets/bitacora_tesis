## Invitación y finalidad

Se invita a la persona participante a representar una conversación ficticia de
vishing o una llamada legítima. El objetivo es construir y evaluar un prototipo
académico que analice conversaciones de voz para detectar señales de estafa. No se
utilizarán datos bancarios, credenciales, códigos ni situaciones personales reales.

## Qué implica participar

- Interpretar uno o más roles a partir de una ficha semi-estructurada.
- Permitir la grabación de voz y la generación de una transcripción.
- Duración estimada total: completar antes de reclutar.
- La actividad puede interrumpirse en cualquier momento sin penalización.

## Datos tratados

- Audio de la representación.
- Transcripción y marcas temporales.
- ID pseudónimo de participante.
- Datos demográficos mínimos que se definan como necesarios; no recopilar DNI,
  domicilio ni datos bancarios.

## Uso y acceso

El audio y la transcripción se utilizarán para desarrollar, entrenar, probar y
documentar el Proyecto Final. Tendrán acceso los integrantes y el tutor autorizado.
Los resultados se presentarán de forma agregada o pseudonimizada.

## Riesgos y medidas

El principal riesgo es la posible identificación por la voz. Los archivos se
almacenarán fuera del repositorio público, con acceso restringido. Se eliminarán
datos personales pronunciados accidentalmente durante la revisión. No se simularán
pérdidas reales ni se solicitarán acciones financieras o credenciales auténticas.

## Conservación y retiro

Los datos se conservarán hasta: **fecha pendiente de aprobación**. La persona puede
solicitar el retiro de sus grabaciones hasta el momento en que el conjunto de test
quede congelado o los datos se hayan disociado/publicado de forma irreversible;
este límite debe explicarse y ser aprobado antes de firmar.
