# Seguimientos con el tutor y la cátedra

Esta carpeta conserva el registro histórico de las reuniones con el director o tutor de tesis (Ing. Ernesto Rico),
con un archivo por encuentro: **`AAAA-MM-DD.md`**.

---

## Pautas de redacción

No se utiliza una plantilla rígida de múltiples tablas. Cada reunión se documenta de forma ágil y flexible respetando dos momentos clave:

1. **Temas y consultas para la reunión (Preparación previa):**
   - Breve lista de 3 a 5 puntos que el equipo le presenta al profesor (evidencia reciente, prototipo, documentos) y las decisiones o dudas específicas que se necesita que el tutor valide.
2. **Minuta y resoluciones del profesor (Posterior a la reunión):**
   - Síntesis de las respuestas, observaciones o correcciones dadas por el profesor.
   - Consecuencias prácticas: qué decisiones quedaron formalmente cerradas y qué nuevas tareas o issues se derivan para el siguiente ciclo.

> **Regla:** Mantener el documento conciso (~20 a 40 líneas). No incluir ensayos ni libretos de discurso previo; registrar los hechos y acuerdos reales.
