# Fichas de lectura

Una por paper. Nombre: `AAAA-primerautor-palabraclave.md`.

La ficha se escribe **al leer**, no antes. Cuando se completa, se agrega la entrada correspondiente a
`referencias.bib` con los datos copiados del DOI.

## Plantilla

```markdown
# [Título del trabajo]

- **Autores:**
- **Publicación / año:**
- **DOI o URL:**
- **Fecha de consulta:**
- **Clave BibTeX:**

## En una frase

## Qué hacen

## Cómo lo evalúan
Datos, métricas y resultados reportados.

## Qué limitaciones declaran los propios autores
(La parte más útil para el capítulo 2: es lo que deja espacio a nuestro trabajo.)

## Relación con nuestra tesis
- Nos sirve para: 
- Se diferencia de lo nuestro en: 
- Nos obliga a: 

## Citas textuales que podríamos usar
> "..." (p. N)
```
